# Task Manager Full Stack

Aplicación web desarrollada con **React, Node.js, Express, PostgreSQL y
Prisma** para gestionar tareas de forma sencilla y segura. El proyecto
incluye autenticación con JWT, protección de contraseñas con bcrypt y
operaciones CRUD para administrar las tareas.

## Tecnologías

-   React + TypeScript
-   Node.js
-   Express
-   PostgreSQL
-   Prisma ORM
-   JWT
-   bcrypt

## Instalación

``` bash
npm install
npx prisma migrate dev
npm run dev
```

## Funcionalidades

-   Iniciar sesión
-   Crear tareas
-   Ver tareas
-   Editar tareas
-   Eliminar tareas
-   Rutas protegidas con JWT
